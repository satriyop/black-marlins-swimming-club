# Guardian home review

#50 replaces stacked equally-loud home cards with a compact Hari ini header, an Anak saya identity list, and one featured next-practice action. Family children are listed in full and never taken from the first six squad records. Invited parents with no child see Daftarkan anak; that path still creates the guardian link without a second admin queue.

## Interaction contract

- Compact greeting/date is supporting text. The visual start for family task-view is the child strip, then the next session. Staff/club task-view keeps Catat kehadiran / Jadwalkan and statistics labelled as klub. Dual-role club view adds family shortcuts without treating club stats as child stats.
- Cancellations stay on the home surface. Completed sessions use quieter copy. Multiple unread announcements collapse to a short list plus Lihat semua.
- Progress uses existing results. A comparison sentence appears only for the same stroke, distance, course and source. Missing times are explained; they are not rendered as zero achievement.
- Existing onboarding dismiss, task-view, enrollment, attendance and result rules are unchanged.

## Review evidence

Browser coverage includes guardian, coach, zero/one/three children, a child outside the first six squad rows, cancelled sessions, five important notices, missing results, 390×844 fold, 320 px / 200% text, and both appearances. UI fixtures create and remove only their own synthetic rows in a local PostgreSQL database.
